本專案包含目前版本的完整原始碼、簡潔網頁介面、企畫書、功能與架構說明書、Stage 完成狀態、示範資料、評估題庫，以及建置、測試與啟動腳本。課程講義只隨組員分享 ZIP 提供，GitHub 版本不附講義。

一、先閱讀哪些檔案

1. docs/專案功能與架構說明書.md
   說明專案功能、資料流程、資料結構，以及 Stage 0–6 已完成與待辦事項。
2. AI知識搜尋引擎企畫書_精簡版.txt
   快速理解專題概念與分工。
3. README.md
   查看詳細啟動、設定、測試與部署方式。
4. docs/reference/Lec3.pdf
   組員分享 ZIP 內附老師提供的課程講義；專題規定見第 3–8 頁。GitHub 原始碼不附講義，請從課程平台取得。

二、在 Windows 執行

1. 安裝 JDK 21 或更新版本。需要包含 javac 的 JDK，不能只有 JRE。
2. 完整解壓 ZIP，進入有 README.md、src、web、scripts 的資料夾。
3. 在這個資料夾開啟 PowerShell，執行：

   .\scripts\run.ps1

4. 等終端機顯示伺服器啟動成功，再用瀏覽器開啟：

   http://127.0.0.1:8080

5. 結束時在啟動程式的終端機按 Ctrl+C。

如果 8080 已被其他程式使用，可改執行：

   .\scripts\run.ps1 -Port 8081

並開啟 http://127.0.0.1:8081。

不需要 Maven、Gradle、npm 或資料庫。不要直接雙擊 web/index.html；網頁需要 Java 後端服務。

macOS／Linux 提供 sh scripts/run.sh。這些平台的腳本已附上，但目前驗證主要在 Windows 進行。

三、沒有金鑰也能測試

預設可使用 Wikipedia 與 Crossref 的公開索引，查詢真實百科及學術來源，需網路連線。搜尋主題不限 AI 技術，也可涵蓋地緣政治、哲學與經濟議題；這些來源不等於完整全網搜尋。

若沒有網路，可在「搜尋設定 → 資料來源」選擇「自編示範資料」，操作計數、排名與網址樹。示範結果不是外部網頁，不能當成勝過 Google 的成績。

四、外部 API 設定

分享包不包含開發者的 .env、API 金鑰或帳號。說明書提到的「本機已啟用 Brave」，指開發者先前的驗證環境，不代表組員解壓後會自動取得相同權限。

要使用自己的金鑰，可在專案根目錄複製 .env.example 為 .env；已有 .env 時不要覆蓋。
- BRAVE_API_KEY：啟用 Brave 一般網頁候選搜尋。
- TYPESAFE_API_KEY：選配 Jev 重排。
- OPENAI_API_KEY 與 OPENAI_MODEL：選配 RAG 來源回答。

修改後需重新啟動程式。不要把金鑰貼到群組、報告或 GitHub；使用前自行確認服務額度與費用。

五、驗證與交付限制

執行 .\scripts\test.ps1 可重新編譯並驗證核心功能。此測試使用本機與模擬資料，不呼叫付費 API。

目前是本機版本，沒有公開網站。127.0.0.1 指使用者自己的電腦，不能直接把這個網址當作共用連結。

Stage 0–1 功能已具備；Stage 2–4 尚有範圍與實測事項；Stage 5 尚待部署；Stage 6 已有工具，但正式 Google／LLM 比較尚未完成。詳細準備事項以功能與架構說明書的表格為準。
