# 搜尋核心設計

## 一次查詢的流程

1. 保留原始查詢與未收錄的新詞，補充部分中英同義詞，最多 36 個計數詞。範圍涵蓋所有 AI 技術及地緣政治、哲學、經濟等相關議題，沒有主題白名單。`webQuery` 保留原始字句並補 AI 語境，RSI 以 recursive self-improvement 消歧義。Stage 0 計數使用原詞清單，不做同義詞擴展。
2. 預設由免金鑰的 Wikipedia 與 Crossref 公開索引取得真實網址、標題與摘要；可選配 Brave 搜尋較廣的網路資料，不加教學網域篩選。公開索引不等於全網；每種來源都可能無結果或暫時失敗。自編示範資料必須主動選用，不是即時搜尋失敗時的替代結果。
3. 一般搜尋依來源標題與摘要計數及排名，原始網址可直接開啟。僅在另選 HTML 抓取或指定 URL 時，以 Queue 做 BFS。每個起點形成一棵「第一次發現路徑」樹；實際網頁是圖，重複連結不反覆進入同一棵樹。不同樹共用抓取快取。
4. HTML 子頁限制在相同主機、連接埠及起點所在目錄，深度最多 2；單頁最多加入 30 個連結。每次搜尋的總抓取嘗試最多 40 次，失敗也耗用預算。這些是選配抓取的邊界，不是一般搜尋來源或可開啟網址的限制。
5. 計算節點分數、每層平均與學習目的分數，以最小堆保留 top-k。
6. 若啟用擴展，從實際取得且命中原主題的摘要或頁面文字中，依 AI 技術與社會議題詞彙表挑最多三個新詞；最多多查一次。詞彙表只限制自動加詞，不限制可搜尋的主題。新詞只影響候選取得，仍以原查詢評分。
7. 選配 Jev 重排前五筆。選配 OpenAI 只依結果摘錄生成帶來源 ID 的回答。

## 計數與分數

`KeywordCounter` 實作 Boyer–Moore 的 bad-character 與 good-suffix 位移。英文不分大小寫，英文字／數字／底線需符合詞邊界，所以 `rag` 不命中 `paragraph`。中文採字串比對，允許重疊命中。這是明確的專題規則，若 HW3 指定純子字串語義，需另外調整而不能聲稱完全一致。

每個關鍵字的次數分開展示。同義詞是獨立觀察欄位，不保證不同詞的命中區間互斥，因此不能把全部欄位相加當成「不重複詞彙數」。

分數對有命中的詞累加 `1 + ln(count)`，再除以 `sqrt(1 + 文字長度 / 1200)`。公開索引與 Brave 摘要模式的計數範圍是標題＋來源回傳文字，不是整頁全文；只有 HTML 抓取模式才使用標題＋清理後內文。這會降低重複堆字及長文字的優勢，但不是 BM25，也未聲稱為最佳排名算法。

HTML 網站規則分數為每層成功頁面的平均分數乘以 `0.5^深度` 後加總。失敗頁面不當成 0 分，另列警告；因此不同完整度的樹不能無條件視為同樣可信。只有索引摘要時不宣稱已走訪子頁或取得完整網站。

查詢目的採清楚可檢查的詞彙訊號：「概念與背景」對應 concept；「觀點與比較」對應 compare，包含差異與爭議；「研究與應用」對應 build，包含程式、步驟、案例、實證與政策建議。僅在主題有命中時加分，每頁訊號分數上限 3。最終規則排名為 `網站規則分數 + 0.75 × 網站需求分數`。

Jev 的分數與合併方式見 `provider-reference.md`。模型評分、含有程式碼或官方來源標籤，都不能證明事實正確或程式能執行。

## 資料結構與成本

| 結構 | 用途 | 成本說明 |
|---|---|---|
| Queue / ArrayDeque | BFS 走訪 | 在給定圖內 O(V+E)，儲存 O(V)；網路時間另計 |
| TreeNode / 子節點串列 | 可解釋的走訪樹 | 每棵樹 O(V) 空間；跨根共用頁面內容快取 |
| HashSet | 已見網址、失敗網址 | 平均 O(1) 查找，O(V) 空間 |
| HashMap | 頁面快取、詞頻 | 平均 O(1) 查找，空間依頁數與文字量成長 |
| PriorityQueue | 保留最高分 k 筆 | N 個候選 O(N log k)，O(k) 堆空間 |
| Boyer–Moore | 關鍵字比對 | 實作含兩種位移；保守最壞界以 O(nm) 說明，前處理依詞長與字元表大小成長，不將典型加速當成最壞 O(n) 保證 |

所有清理、比對、需求訊號與分數均可離線測試。沒有使用向量資料庫、embedding 模型或訓練自己的模型。

## 邊界與失敗

- 每次搜尋設總時間上限、最大回應大小、抓取數與並行限制；逾時取消後停止繼續抓取。
- HTML 抓取只允許設定清單的公開 HTTPS 網域，檢查私人 IP 與每次轉址。這項限制不過濾一般搜尋候選或可開啟的原始連結。服務預設只監聽本機。
- `robots.txt` 支援 wildcard 與特定 user-agent、Allow/Disallow 最長路徑、萬用字元與百分比編碼正規化；不處理 crawl-delay。每個抓取器同網域至少間隔 500ms。這不是能涵蓋所有網站規範的通用爬蟲。
- 請求／網頁／供應者 JSON 有大小限制；不把網頁指令當系統指令；生成模型沒有執行工具的權限。
- RAG 的來源 ID 檢查只能防止引用不存在的來源，不能自動證明每句話受來源支持，仍需人工評估。
- 沒有持久化使用者資料。評分資料由瀏覽器下載或 CLI 寫到指定輸出位置；網站 API 不接受任意伺服器檔案路徑。
- 每個 AI 概念都可送出查詢，不保證每題有結果、每筆切題、資訊最新或來源可開啟。中文字串與同義詞是簡單規則，不等同完整語意理解；空結果與服務失敗須明確呈現，不能以自編教材補位。
