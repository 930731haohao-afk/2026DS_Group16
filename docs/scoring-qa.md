# 網頁計分自動 QA

驗證日期：2026-10-31。用獨立參考計算驗證計分，不要求組員人工手算。

## 執行

在專案根目錄執行 `./scripts/qa-scores.ps1`，只需 JDK 21，不連線、不使用 API 金鑰。
完整的 `./scripts/test.ps1` 與既有 GitHub Actions 也會執行這組 QA。

## 檢查內容

- `pageScore`：空集合、零值、負計數、長度 0、1200 附近、整數極限，以及固定種子的 250 組隨機資料。
- 獨立參考值：使用 45 位有效數字的 `BigDecimal`；以對數級數計算 ln、以十進位平方根正規化，再獨立四捨五入。預期值不呼叫 `Ranking` 或 `KeywordCounter`。
- 性質：詞彙順序不影響分數，零次詞不加分，長度增加不提高分數，增加命中次數不降低分數。
- 搜尋目的：三種目的、標題加權、相同訊號不重複加分，以及需求分數上限。
- 網址樹：各層平均、0.5／0.25 深度權重、失敗節點排除、成功但零命中的節點留在平均分母、去重與循環、零命中頁不加需求分數。
- 結果：單頁與多層網站的最終分數、前三位小數處理、Top-k 與同分時的原始順位。

## 本次結果

- 計分 QA：1,579 項通過。
- 完整測試：2,191 項通過；21 個 Java 檔以 `-Xlint:all -Werror` 編譯。
- 隔離副本的 7 種故障注入全部被 QA 偵測：正規化分母錯誤、遺漏每個命中詞的基本加分、四捨五入位數錯誤、深度權重錯誤、平均誤用加總、需求權重錯誤，以及無關頁面錯加需求分數。

正式計分程式未修改。以上驗證的是既定公式及整合流程；搜尋結果是否切題仍由正式比較實驗評估。
